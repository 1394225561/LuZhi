# Phase 6 / W11-W12 自测清单：导出预设与本地授权

## 目标

验证 16:9、9:16、1:1 三种导出预设可用，本地试用状态和激活状态接口可展示，MVP 可交付种子用户测试。

## 导出预设验证

- [ ] 16:9 预设可导出 1080p 视频。
- [ ] 9:16 预设可导出 1080p 视频。
- [ ] 1:1 预设可导出 1080p 视频。
- [ ] 导出进度可上报给 UI。
- [ ] 导出可取消。
- [ ] 导出失败时显示中文错误。
- [ ] 输出文件路径合法且不覆盖用户未确认文件。

## 编码与封装验证

- [ ] FFmpeg 使用 binding / C API 封装。
- [ ] 未直接调用 FFmpeg CLI。
- [ ] 用户输入未拼接成命令行参数。
- [ ] 视频和音频轨道均可播放。
- [ ] 裁剪时间线和光标效果时间线可共同生效。

## 授权验证

- [ ] 首次启动可生成 14 天试用状态。
- [ ] UI 可显示试用剩余状态。
- [ ] 试用过期状态可展示。
- [ ] 激活状态接口存在。
- [ ] 授权信息走系统凭据存储或等价安全方案。
- [ ] 未硬编码激活私钥或服务端密钥。

## 稳定性验证

- [ ] 1080p 素材三种比例连续导出无崩溃。
- [ ] 导出过程中 UI 不阻塞。
- [ ] 导出取消后资源释放完整。
- [ ] 录制、处理、导出连续流程可完成。

## 测试要求

- [ ] 导出服务有 Mock encoder 测试。
- [ ] 导出预设参数有单元测试。
- [ ] LicenseService 有本地状态测试。
- [ ] 前端导出对话框有 Vitest 测试。

## 人工审查

- [ ] 授权系统未扩展为完整商业化后端。
- [ ] 没有新增平台发布 API。
- [ ] 没有引入字幕、摘要、知识库、模板系统。
- [ ] MVP 可交付 20 个种子用户测试。
