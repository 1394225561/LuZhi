# Phase 3 / W5-W6 自测清单：录制 UI 与前后端联调

## 目标

验证中文录制流程完整可用，前端仅作为展示和命令层，录制状态机仍由 Rust 统一维护。

## UI 验证

- [ ] 全屏录制入口显示中文文案。
- [ ] 窗口录制入口显示中文文案。
- [ ] 区域录制入口显示中文文案。
- [ ] 分辨率和帧率参数可选择。
- [ ] 系统音频和麦克风开关可选择。
- [ ] 权限缺失时显示中文引导。
- [ ] 录制中显示时长和当前状态。
- [ ] 停止录制后进入预览或完成状态。

## 前后端联调

- [ ] 前端使用 Tauri invoke 发起开始录制。
- [ ] 前端使用 Tauri invoke 发起停止录制。
- [ ] Rust 通过 event 下发状态变化。
- [ ] Rust 通过 event 下发错误和进度。
- [ ] UI 状态完全来自 Rust 下发事件。

## 架构红线

- [ ] 前端未接收视频帧。
- [ ] 前端未接收音频流。
- [ ] 前端未实现录制状态机。
- [ ] 前端未直接拼接 FFmpeg 参数。

## 稳定性验证

- [ ] 快速点击开始/停止不会导致状态错乱。
- [ ] 录制失败后可恢复到可再次录制状态。
- [ ] 设备不可用时不崩溃。
- [ ] 权限变更后重新检测状态正确。

## 测试要求

- [ ] React 录制控制组件有 Vitest 测试。
- [ ] Tauri `invoke` 已 mock。
- [ ] 错误提示组件有测试。
- [ ] 权限提示组件有测试。

## 人工审查

- [ ] 应用界面文字均为中文。
- [ ] 没有引入 Antd/Arco 等重型 UI 库。
- [ ] 没有将核心业务逻辑放入 React 组件。
