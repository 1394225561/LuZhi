# Phase 6 手动 FFmpeg Gate 清单

> 每项执行人标记 `[x]` 或 `[!]`（失败），并注明日期与环境。

---

## G-1: 1080p 10 分钟压力测试

**目标**：确认导出管线在 1080p、10 分钟录制时稳定运行，无 panic、无明显内存泄漏。

- [ ] **G-1a**：录制 10 分钟 1080p 全屏（含系统音频 + 麦克风）
- [ ] **G-1b**：录制完成后，在 Preview 页导出 Bilibili 16:9 预设
- [ ] **G-1c**：导出过程中观察 CPU/内存占用（Activity Monitor）
- [ ] **G-1d**：导出完成后，验证输出文件可被 VLC / IINA 正常播放
- [ ] **G-1e**：导出完成后，验证输出文件时长与录制时长基本一致（误差 < 2s）

**通过条件**：无 panic、无 OOM、输出可播放、时长正确。

---

## G-2: A/V 同步测试

**目标**：确认导出文件的音频与视频同步。

- [ ] **G-2a**：录制 30 秒，期间播放有节奏的音频（如节拍器）
- [ ] **G-2b**：导出后播放，验证音频节拍与画面动作同步
- [ ] **G-2c**：录制 30 秒，期间进行快速鼠标操作
- [ ] **G-2d**：导出后播放，验证鼠标点击声音与画面点击同步

**通过条件**：音频与视频偏移 < 100ms。

---

## G-3: 原始素材保留测试

**目标**：确认导出不覆盖或删除原始录制文件。

- [ ] **G-3a**：录制一段短视频（10 秒）
- [ ] **G-3b**：记录原始文件路径和大小
- [ ] **G-3c**：导出 Bilibili 预设
- [ ] **G-3d**：验证原始文件路径、大小未变
- [ ] **G-3e**：验证导出文件路径与原始文件不同

**通过条件**：原始文件完整保留，导出文件独立存在。

---

## G-4: 取消清理测试

**目标**：确认取消导出后，partial output 被清理。

- [ ] **G-4a**：录制一段视频
- [ ] **G-4b**：开始导出，立即点击取消按钮
- [ ] **G-4c**：验证导出目录中无残留的 partial output 文件
- [ ] **G-4d**：再次导出（不取消），验证正常导出成功

**通过条件**：取消后无残留文件，正常导出仍可成功。

---

## G-5: 三种预设尺寸验证

**目标**：确认三种预设的输出分辨率正确。

- [ ] **G-5a**：导出 Bilibili 预设 → 用 `ffprobe` 验证 1920×1080
- [ ] **G-5b**：导出抖音预设 → 用 `ffprobe` 验证 1080×1920
- [ ] **G-5c**：导出小红书预设 → 用 `ffprobe` 验证 1080×1080

**通过条件**：每种预设输出分辨率与 `ExportPresetSpec` 一致。

---

## G-6: 无 FFmpeg 构建 Gate 测试

**目标**：确认无 FFmpeg 构建下，`export_video` 返回清晰错误。

- [ ] **G-6a**：不带 `--features ffmpeg` 编译
- [ ] **G-6b**：调用 `export_video`，验证返回 "FFmpeg 导出功能未启用" 错误

**通过条件**：无 panic，返回明确中文错误信息。
