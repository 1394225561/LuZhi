# Phase 4 / W7-W8 自测清单：光标平滑与点击放大

## 目标

验证光标轨迹采集、移动平均滤波、贝塞尔插值和点击放大状态机可生成稳定的 `EffectTimeline`。

## 元数据采集

- [ ] 录制期能记录 `CursorSample`。
- [ ] 录制期能记录 `CursorClick`。
- [ ] 光标事件与视频帧使用同一时间基。
- [ ] 光标元数据保存到中间录制元数据中。

## 算法验证

- [ ] 0 帧输入返回空轨迹。
- [ ] 单点输入保持原位置。
- [ ] 高频抖动输入被平滑。
- [ ] 快速跨区域移动不过度拉平。
- [ ] 30fps 和 60fps 使用不同自适应窗口。
- [ ] 贝塞尔插值输出覆盖每个视频时间戳。

## 点击放大验证

- [ ] `Idle -> PressedExpand -> Hold -> ReleaseShrink -> Idle` 状态迁移正确。
- [ ] 点击瞬间有放大效果。
- [ ] 放大后能平滑恢复。
- [ ] 连续点击不会导致状态卡死。
- [ ] 点击效果写入 `EffectTimeline`。

## 导出验证

- [ ] 录后处理可读取光标时间线。
- [ ] 导出视频包含光标平滑效果。
- [ ] 导出视频包含点击放大效果。
- [ ] 原始录制素材不被破坏。

## 性能验证

- [ ] 光标算法不会阻塞捕获线程。
- [ ] 录后处理进度可上报。
- [ ] 1080p 素材处理过程中内存无无界增长。

## 测试要求

- [ ] 移动平均滤波有单元测试。
- [ ] 贝塞尔插值有边界测试。
- [ ] 点击放大状态机有单元测试。
- [ ] `EffectTimeline` 序列化和反序列化有测试。

## 人工审查

- [ ] 算法注释说明核心数学思路。
- [ ] 没有将光标效果实时压入捕获主链路。
- [ ] 没有为 V2 自动缩放提前实现复杂逻辑。
