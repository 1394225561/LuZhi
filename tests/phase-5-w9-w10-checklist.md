# Phase 5 / W9-W10 自测清单：空白段检测与自动裁剪

## 目标

验证音频 RMS、低分辨率帧差分和裁剪时间线可保守识别长空白段，并通过 FFmpeg 封装完成裁剪导出。

## 音频 RMS 验证

- [ ] 500ms 到 1000ms 滑动窗口可配置。
- [ ] 静音段能被识别。
- [ ] 短暂停顿不会默认进入裁剪候选。
- [ ] 背景噪声存在时阈值表现可解释。

## 帧差分验证

- [ ] 帧差分使用低分辨率灰度图。
- [ ] 完全静止画面变化率接近 0。
- [ ] 加载动画不会被误判为完全静止。
- [ ] 鼠标移动能贡献画面变化信号。
- [ ] 抽样频率不会影响主录制帧流。

## 裁剪策略验证

- [ ] 只有音频静音和画面低变化同时满足才进入候选。
- [ ] 小于 2 秒静默不裁剪。
- [ ] 超过 5 到 8 秒低变化片段进入候选。
- [ ] 候选段前后保留 300 到 500ms 缓冲。
- [ ] 相邻候选段可正确合并。
- [ ] 输出 `CutTimeline` 可解释。

## 导出验证

- [ ] FFmpeg 封装能消费 `CutTimeline`。
- [ ] 裁剪后视频可播放。
- [ ] 音视频同步未明显漂移。
- [ ] 原始素材保留。
- [ ] 取消裁剪后可按原素材重新导出。

## 测试要求

- [ ] RMS 检测有单元测试。
- [ ] 帧差分有边界测试。
- [ ] 裁剪候选合并有单元测试。
- [ ] 裁剪时间线空输入、重叠输入、连续输入均有测试。

## 人工审查

- [ ] 裁剪默认策略足够保守。
- [ ] 没有直接删除原始素材。
- [ ] FFmpeg 调用未拼接用户输入字符串。
