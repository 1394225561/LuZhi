## 手动验证

- [ ] 折叠状态下，历史录制按钮外侧没有常态白色细线或阴影圈
- [ ] 展开历史录制侧栏后，侧栏左侧没有由按钮边框或侧栏阴影形成的细线
- [ ] 折叠历史录制侧栏后，窗口右边缘不残留整高细线
- [ ] 折叠状态下，历史录制按钮下边缘与开始录制主面板上边缘重合
- [ ] 折叠状态下，历史录制按钮相对开始录制主面板右边缘向左内收，避开右上圆角缺口
- [ ] 展开过程中，历史录制按钮先停留在默认位置，直到侧栏左边缘接触按钮右边缘后再向左移动
- [ ] 侧栏左边缘接触按钮右边缘后，按钮右边框在整个移动过程中始终与侧栏左边框重合
- [ ] 展开完成后，历史录制按钮右边框与侧栏左边框保持贴合，两者之间没有空隙且不重叠
- [ ] 点击历史录制按钮仍能展开侧栏
- [ ] 展开后点击关闭按钮仍能折叠侧栏
- [ ] 历史记录点击跳转和删除按钮功能保持正常
