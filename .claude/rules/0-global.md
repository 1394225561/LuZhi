# 项目级全局规则

## 1. 项目目标

项目概述，项目想到达到的目标、效果，项目做什么、不做什么。

### 1.1 核心愿景

打造中国版 Screen Studio，核心执行原则： **砍掉一切非核心功能，把“录屏 + AI 美化”做到极致。** 任何偏离此原则的功能提议均视为违规。

### 1.2 MVP 功能锁定（Must Have）

- 录制：全屏/窗口/区域（1080p/4K），系统音频 + 麦克风。
- AI 美化：光标放大 + 平滑轨迹（贝塞尔插值），自动裁剪空白段（静音 + 帧差分检测）。
- 导出：16:9 (B站)、9:16 (抖音)、1:1 (小红书) 一键格式转换。
- 商业化：14天试用 + 激活码买断。

### 1.3 绝对禁忌（Must NOT Have）

- **禁止** 实现字幕、摘要、知识库、模板系统、团队协作功能。
- **禁止** 在 MVP 阶段实现快捷键叠加、背景美化、自动缩放关键区域（这些属于 V2+ 阶段）。
- **禁止** 碰触任何平台（B站/抖音等）的发布 API，仅做本地格式转换。

### 1.4 里程碑对齐

所有代码生成需对照 "@docs/PRD/LuZhi_PRD_final_version.md" 开发里程碑，当前优先级：
**W1-2 脚手架与录制引擎原型 > W3-4 双平台音频 > W5-6 UI > W7-8 光标美化 > W9-10 裁剪 > W11-12 导出与授权** 。

## 2. 项目具体的架构、技术栈

### 2.1 技术栈锁定

| 层级      | 选型                                       | 约束                                                  |
| --------- | ------------------------------------------ | ----------------------------------------------------- |
| 桌面框架  | Tauri 2.0                                  | 禁止降级至 1.x，充分利用 2.x 的多窗口和权限系统       |
| 前端 UI   | React + TS + Tailwind                      | 组件库统一使用 shadcn/ui，禁止引入 Antd/Arco 等重型库 |
| 录制引擎  | macOS: ScreenCaptureKit Win: DXGI + WASAPI | 必须封装为统一的 Rust Trait，隔离平台差异             |
| 视频处理  | FFmpeg (ffmpeg-next)                       | 禁止直接调用 CLI，必须使用 C API binding              |
| 光标/渲染 | Rust 原生 + GPU                            | 光标平滑必须在独立线程/进程计算，避免阻塞录制主循环   |
| 音频处理  | cpal + FFmpeg                              | 混音逻辑放在 Rust 侧                                  |
| 监控      | Sentry + PostHog                           | 必须异步上报，不得影响录制性能                        |

### 2.2 三层架构约束

1. **UI Layer (React)** ：纯展示与交互捕获，无业务逻辑。通过 Tauri Event/Invoke 与后端通信。
2. **App Logic (Rust)** ：核心状态机（录制、暂停、处理中、导出中）、业务编排。
3. **Native Modules (Rust/FFI)** ：底层硬件交互，直接操作 ScreenCaptureKit/DXGI/FFmpeg。

**数据流红线** ：视频帧流和音频流 **严禁经过前端 JS 层** ，必须完全在 Rust 侧完成“捕获 -> 缓存 -> 处理(美化/裁剪) -> 编码导出”的闭环。前端仅获取录制状态、时长、缩略图等轻量数据。

### 2.3 难点架构预案（AI 生成代码需对齐）

- **帧数据处理** ：需使用 Ring Buffer 或共享内存机制，解决捕获线程与编码线程的速度差。
- **4K 性能瓶颈** ：处理 4K 画面时，CPU 仅做编排，渲染（圆角、光标放大、背景模糊） **必须** 交由 GPU (Metal/DX12 Compute Shader 或至少利用硬件编解码)。
- **音频同步** ：系统音频与麦克风混音时，必须基于时间戳对齐，禁止基于帧数硬对齐。
